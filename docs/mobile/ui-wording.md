# Mobile: UI wording

From the original spec unless marked.

| Where | Text |
|---|---|
| Requester Home | "Ask someone nearby" |
| QR expired modal | "Nobody scanned" with a "Try again" button |
| Stop sheet | "Stop receiving? More pics are on the way." Buttons "Stop" and "Keep waiting" (Keep waiting is the default) |
| Helper buffer full | "All 5 sending, one second…" |
| Helper sending toast | "Sending…", brief, fades by itself |
| Helper Wrap-up | "Thanks for helping! Still sending in the background." with "Done" |
| Helper session ended | Modal: "Session ended. Thanks for your help!" |
| Requester Summary | "N photos received" with a link to Photos |
| Code already used | proposed: "This code was already used" |
| Code invalid or expired | proposed: "This code isn't valid anymore" |
| Offline | proposed: "No connection. You need to be online to help." |
| QR screen title | proposed (iOS slice): "Ask them to scan this code", with a countdown and "Cancel" |
| Claimed, waiting for the first photo | proposed (iOS slice): "They're taking your photos…" |
| Summary buttons | proposed (iOS slice): "Open Photos", "Done", and "View photos kept in the app" when some went to the in-app gallery |
| Photos kept in the app | proposed (iOS slice): "Photo access is off, so photos are kept in the app." |
| Remove | proposed (iOS slice): "Remove" (long press on a photo); failure "Couldn't remove that photo." |
| Create failed | proposed (iOS slice): offline "No connection. Check your internet and try again."; rate limited "Too many tries. Wait a minute and try again."; else "Something went wrong. Try again." |
| Photo library usage texts (iOS) | proposed: add-only "PicPlease saves the photos people take for you to your library."; full "PicPlease needs full access only to remove a received photo you choose to delete." |
| Web: camera access | proposed (web W5): "To take their photos, PicPlease needs your camera." Button "Allow camera" |
| Web: no camera, denied | proposed (web W5): "Camera access is off. Turn it on for this site in your browser settings, then reload." |
| Web: no camera, unavailable | proposed (web W5): "This browser can't use the camera. Try another browser, or get the app." |
| Web: code problem, server unreachable | the Offline text: "No connection. You need to be online to help." |
| Web: shooting | proposed (web W5): shutter label (screen readers) "Take photo"; link "Finish"; count "N sent" |
| Web: get the app (after the thank-you and on no camera) | proposed (web W5): "Get the app" with "App Store" and "Google Play" buttons; a button is hidden while its store link is not set |
| Web: after Finish, photos still sending | proposed (web W5, owner's wording): "Sending photo, please keep this open." with the sent count; the mobile "Still sending in the background" is not used because closing the tab stops uploads |
| Web: everything sent | proposed (web W5): "Thanks for helping!" then Get the app |
